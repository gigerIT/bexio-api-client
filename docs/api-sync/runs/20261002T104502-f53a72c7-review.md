The user confirmed this is a trial account and requested a workaround rather
than enabling paid features. Local `.env` now sets `BEXIO_TEST_ACCOUNT_PLAN=trial`.
CI uses the same default; a repository variable set to `full` restores those live
checks. Token contents were preserved.

Only live payroll and legacy IBAN/QR write flows use the explicit trial gate.
Unexpected HTTP failures are still failures when that gate is unset. Exact
mocked IBAN/QR create/update/show contract tests run on both account modes.

- Added `DownloadPaystubPdfRequest` for the binary PDF endpoint. Method/path and
  binary-byte preservation tests pass. Live verification remains pending because
  even the employee-list prerequisite returns HTTP 403 on this account.
- Marked the older JSON-location paystub request deprecated without removing it.
- Added VAT period `start`/`end` mapping, `type` (including `annual`) and
  `closed_at`. Unit index/show hydration passes. Live list calls return no VAT
  periods, so the new fields still lack live verification.
- Legacy IBAN/QR create returned HTTP 403 before the explicit trial gate was
  added. Existing request APIs remain available; a trial restriction does not
  establish that an endpoint has been retired.
